\section{Experimental Setup}
\label{sec:experimental}

\subsection{Hardware and Software}
\label{sec:experimental-hardware-software}

All experiments ran on a single laptop with an NVIDIA GeForce RTX 3070
Ti Laptop GPU (8 GB) under Windows 11, with Python 3.12.13, numpy
2.5.1, pandas 3.0.5, scikit-learn 1.9.0, xgboost 3.3.0, PyTorch
2.11.0+cu128, pvlib 0.15.2, and statsmodels 0.14.6; exact versions are
recorded in every result file and pinned in requirements.txt.
Gradient-boosted models were fitted on CPU - at this dataset size
(roughly 11,200 daylight training rows per array, 37 features), GPU
execution offers no throughput benefit and introduces nondeterminism -
and recurrent models on the GPU.

\subsection{Hyperparameters}
\label{sec:experimental-hyperparameters}

Hyperparameters were fixed a priori and not tuned; a repository search
confirms no grid search, no tuning loop, and no default changed after
its introduction. XGBoost used 500 estimators, maximum depth 6,
learning rate 0.05, subsample 0.8, column subsample 0.8, and early
stopping after 50 rounds without improvement on validation. Both
recurrent models used a single layer of 64 hidden units, sequence
length 24, batch size 256, learning rate $10^{-3}$ with Adam, up to
100 epochs, and early stopping with patience 10 on validation RMSE; the
CNN-LSTM added a 1-D convolutional front end with 32 filters and kernel
size 3. The residual stage used 300 estimators, maximum depth 4,
learning rate 0.05 - deliberately smaller than the standalone
gradient-boosted model, since it fits residuals rather than the
target. Networks were kept small deliberately: the training set is
small by deep-learning standards, and larger capacity would invite
overfitting rather than improve the comparison.

\subsection{Seeds and Reproducibility}
\label{sec:experimental-seeds}

Every configuration was run with five random seeds (0-4); Python,
NumPy and PyTorch seeds were set explicitly and recorded. Full
determinism was not achieved - torch.nn.LSTM provides no deterministic
CUDA backward pass, and result files record
full\_determinism\_achieved = false for all recurrent runs - which is
why seed variance is reported alongside every recurrent result. All
figures and tables are generated from these records by repository
scripts and were verified byte-identical on regeneration from a clean
state (Section I).

\subsection{Data and Code Availability}
\label{sec:experimental-availability}

The DKASC data are openly available \cite{dkasolarcentre}. All code,
configuration, and the complete set of 900 run records are available
at an anonymised repository, link withheld for review.
